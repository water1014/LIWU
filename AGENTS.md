# LIWU Agent Instructions

For every interface, layout, styling, navigation, or interaction task, read `design-system/liwu/MASTER.md` before editing.

Treat that file as the project's active design system and preservation contract. LIWU is a mobile-first private companion space, not a 3D room or magazine website.

Do not remove features, navigation entries, settings, user-facing copy, or local data behavior unless the user explicitly asks. Inspect shared dependencies before editing. Keep changes scoped and verifiable. No bottom navigation bar. No 3D/WebGL unless explicitly requested.

After each UI change, check mobile safe areas, independent scrolling, composer visibility, 44px touch targets, contrast, reduced motion, and both themes where applicable.
