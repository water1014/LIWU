# 里屋

一间能说话、能记事、能住人的屋子。一个完整的聊天前台，手机上打开就能用。

## 怎么开始

1. 左上角 `≡` → 最下面一排点 **设置**
2. 填三个东西：接口地址、Key、模型。上面三个胶囊键（DeepSeek / OpenAI / OpenCode Go）能一键填前两个
3. 点 **试一下**，看到“通了”就行，再点 **存好**
4. 回到聊天，说一句

报 `Failed to fetch` 就是浏览器不让网页直连接口（跨域），在手机 Ubuntu 里跑：

```
python3 proxy.py
```

地址改成 `http://127.0.0.1:8790/v1`，再试。

## 能干什么

- **多段会话**：左边抽屉里列着，能搜、能改名、能删。每段自己攒上下文
- **流式吐字**，中途能按停
- **思考链**：模型如果回了 reasoning，会折在“它想了一下”里
- **单条操作**：复制、重发、重新生成、删掉
- **系统提示词**自己能改，决定它是谁
- **温度、上下文条数、流式开关**都能调
- **夜间主题**
- **导出 / 导入**：一份 JSON，含全部会话和配置
- **日记 / 相册 / 记忆**：三个小房间，从抽屉里进
- **在一起多少天**：在设置里填起算日，顶栏和抽屉都显示

## 文件

| 文件 | 管什么 |
| --- | --- |
| `index.html` | 骨架。顶栏、消息流、输入框、抽屉、全屏页 |
| `assets/style.css` | 所有样式。两套主题的颜色都在顶上 |
| `assets/app.js` | 所有逻辑。分段写着：工具 → 配置 → 会话 → 聊天 → 抽屉 → 房间 → 设置 |
| `data.js` | 内容：时间轴、日记、相册清单、记忆 |
| `proxy.py` | 可选。本机中转，绕开跨域 |

想改颜色就改 `style.css` 顶上那两组变量；想改它说话的方式就在设置里改系统提示词；想改功能在 `app.js` 里按段找。

## 还没有的

这些是真没有，不是藏起来了：

- 工具调用、插件、MCP
- 看图、语音
- 记忆检索（记忆只是一页清单，不会自己参与上下文）
- 把对话写回仓库（现在只在本栀 localStorage）
- 图上传来

想加哪一件，按顺序来，一件一件加。

## 数据在哪

全部在浏览器 localStorage：

- `liwu.v3` 会话
- `liwu.cfg3` 配置（含 Key）
- `liwu.diary` 日记
- `liwu.since` 起算日

换手机或清缓存就没了。想搬走就用设置里的“导出全部”。
