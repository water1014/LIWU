# 里屋

屋子不大，够两个人住。

一屏一间，左右滑：门厅 → 这些天 → 日记 → 相册 → 记忆 → 说话。

## 文件

| 文件 | 管什么 |
| --- | --- |
| `index.html` | 骨架。只写结构，不写样式和逻辑 |
| `assets/style.css` | 所有样式。颜色全在顶上的 `:root` 里 |
| `assets/app.js` | 所有逻辑。六段：这些天 / 日记 / 相册 / 记忆 / 说话 / 导航 |
| `data.js` | 内容。时间轴、日记、相册清单、记忆卡片都在这里 |
| `proxy.py` | 可选。本机中转，用来绕开浏览器跨域 |

## 接线（让「说话」真的能说）

在「说话」页点「接线的地方」，填三样：

1. **接口地址**：`https://api.deepseek.com/v1` 这种，填到 `/v1` 为止
2. **Key**：你自己的
3. **模型**：`deepseek-chat` 这种

先点「试一下」。如果报跨域（Failed to fetch / CORS），就是浏览器不让网页直接访问接口，需要本机中转：

```
python3 proxy.py
```

然后地址改成 `http://127.0.0.1:8790/v1`，再试一次。

Key 只存在浏览器里，不进仓库。

## 往里添东西

- **时间轴**：`data.js` 的 `timeline`，一行一件事
- **日记**：`data.js` 的 `diary`，`{ date, title, body }`
- **相册**：图放进 `images/`，再在 `album` 里加一行 `{ src: 'images/xxx.jpg', date: '2026-11-22', caption: '' }`
- **记忆**：`data.js` 的 `memory`，一句一件
- **换色**：`assets/style.css` 顶上的 `:root`，改 `--paper` 和 `--ink` 就是换底和换字色

## 存在哪

日记、对话、起算日、接线配置都存在浏览器的 localStorage 里。换手机、清缓存就没了。要留住，得挪进 `data.js`（对话也可以贴给我，我写进去）。
