# LIWU · 小手机

一台只存在于浏览器里的手机。桌面、聊天、世界书、记忆、表情、日记都在一个静态站点里，数据只写进本机 IndexedDB，不发往任何服务器。

> 这是**多文件工程**版本：源码按层拆开，浏览器直接加载，不再依赖打包。想发给别人一个文件时再用 `build.py` 压成单 HTML。

---

## 怎么跑

**方式一：本地起一个静态服务（推荐）**

```bash
cd liwu
python3 -m http.server 8000
# 打开 http://localhost:8000
```

只有 http/https 下才能注册 Service Worker、装成 PWA、离线打开。

**方式二：直接双击 `index.html`**

也能完整运行（脚本是普通 `<script>`，不是 ES Module），但装不了 PWA，`file://` 下部分浏览器的 IndexedDB 行为不一致。

**方式三：打包成单个 HTML 分享**

```bash
python3 build.py     # 产物：dist/liwu.standalone.html
```

## 这一版补了什么

| 模块 | 说明 |
| --- | --- |
| **多文件工程** | 样式与脚本各自成文件，浏览器原生加载；保留可选打包 |
| **PWA** | `manifest` + Service Worker，可添加到主屏、断网打开 |
| **表情库** | 上传图片、命名、改名、删除可撤销；名字进提示词名单，AI 输出 `[表情:名字]` 渲染成图片气泡 |
| **接口对接层** | 地址自动补 `/v1` 或 `/v1beta`，两种候选各试一次；401/403/404/429/超时/非 JSON 都翻译成人话 |
| **世界书范围** | 全局书对所有角色生效，手动绑定的书只对指定角色生效 |
| **果冻反馈** | 按下 0.08s 快速压缩，松开 0.6s 过冲回弹；只碰 `transform`，不与配色打架 |
| **轻提示可撤销** | 删除表情等操作给出撤销入口，提示条带操作按钮 |
| **我们** | 在一起的天数、今天的提醒、胶囊 / 词云 / 月度 / 小房间的入口 |
| **小房间** | 待办、便签、心愿、打卡四个页签，共用一个入口 |
| **时间胶囊** | 写一封信封起来，到期前打不开；拆开是一张纸 |
| **词云** | 本机分词 + 词表匹配，取高频实词，按频次分档排版 |
| **月度回顾** | 六项数据、每日柱状图，和一封按真实数字写成的信 |
| **额度** | 请求次数、输入 / 输出 token、失败数、七天柱状图 |

原有功能都在：桌面纵向滚动、组件增删与拖动换序、聊天多账号、思考折叠、旁白、长按编辑/删除/重回、气泡与聊天室 CSS、世界书条目（前/中/后 × 始终/关键词/概率）、三级记忆与自动总结、档案、商店、通知、美化、API 三协议、提示词分块开关、数据管理、音乐、书架、纪念日与日记。

「我们」这一组全部离线计算：词云从 IndexedDB 里的消息切词，月度回顾读的是每日消息计数，额度读的是接口返回的 `usage`（没有就按字数估）。

## 数据

- 全部写在浏览器 IndexedDB 的 `LIWU_DB` 里：账号、角色、会话、消息、世界书、记忆、设置、图片文件。
- 图片存 Blob，运行时生成临时 URL 并缓存；刷新后重新生成，不会裂图。
- 表情上传只压超过 300 KB 的图，透明底不会被转黑。
- 「设置 → 数据」可以按表查看占用、单独清空或全部清空。

## 已知取舍

1. 没有真实音频文件，音乐页只是界面里的播放状态。
2. 未配置接口时走本地模拟回复，语气是规则拼的，不是模型。
3. 消息列表按 40 条一屏渐进加载，没有做虚拟滚动；几千条以上会变慢。
4. 桌面组件按纵向流式排列，拖动可改顺序；不做像素级自由定位。
5. 提示词里的世界书与记忆是拼接式注入，不做向量检索。
6. 浏览器直连接口要求对方允许 CORS；不支持的线路需要自建代理。
7. 词云用的是内置常用词表 + 正向最大匹配，不是真分词：生僻词、人名会漏，宁缺勿滥。
8. 额度只统计调用次数与 token，不显示余额——不同中转站计价方式不一样。

## 主屏结构（v9）

主屏是**左右翻页**的：一页一屏，滑动切换，底部有页点。

桌面是一张 **4 列格网**，图标占 1×1，小组件占 2×2，横幅卡占 4×2（拍立得、音乐、日历是 2×3）。图标和组件排在**同一条流**里，所以会自然错落——四个图标、一张横幅、两个图标加一张对话卡，都可以落在同一行。

排布由 `HOME.js` 里的 `flow()` 与 `homePages()` 决定：

1. `flow()` 把「图标 + 组件」拼成一条有序清单，拖拽后顺序存在 `S.cfg.flow`；
2. `homePages()` 用 occupancy 矩阵按 4 列装箱，图标 1 格、组件 2×2 或 4×2，逐行找空位；
3. 按每页可用行数切页，绝不把一张卡切在两页之间；
4. 格位算好后用**绝对定位**落到 `left / top / width / height`，不依赖 CSS Grid 的行分配（那样会被内容撑变形）。

格高 `GRID.row = 76`、间距 `GRID.gap = 10`，窄屏（<380）自动降为 72 / 9。

## 开屏

每天第一次打开会先看到锁屏（时间 / 日期 / 一张「together」小卡），向上轻扫解锁。
关闭路径：设置 → 美化 → 背景 → 开屏。开关写在 `S.cfg.ui.lock`，解锁日期记在 `S.cfg.ui.lastUnlockDay`，所以一天只出现一次。

## 质感层（v8）

样式分两层：`10-look.css` 管布局与层次，`11-polish.css` 管「编辑感」——衬线时钟与刊号、统一的玻璃图标底、卡片内描边、页点与 dock 的比例。改视觉优先动 11，不要回头改 01/02 的原始值。

长按任意卡片进入编辑：右上角 × 删除，拖动换序（只在本页内换），底部「恢复默认」回到初始排布。

## 入口原则

一个功能只有一个入口：

| 功能 | 唯一入口 |
|---|---|
| 聊天 / 朋友圈 / 世界书 / 音乐 / 书架 / 时光 / 记忆 | 主屏图标 |
| 我们（小房间 / 时间胶囊 / 词云 / 月度回顾） | 主屏「我们」→ 目录页 |
| 额度 / 数据 / API / 提示词 / 美化 | 设置 |
| 表情库 | 聊天 → 发现 |

## Only us（v10 新增）

「我们」页下的三条，都不联网、都存在本机：

| 入口 | 内容 | 存哪 |
| --- | --- | --- |
| 他的消息 `messages` | 按日子长出来的早安晚安，可标记已读、可让他再说一句 | `S.cfg.extra.hisMessages` |
| deeptalk | 像写信，一张一张；读完可一键收进永久记忆 | `S.cfg.extra.deepTalks` → `memories` |
| 秘密 | 四位锁，锁着只给自己看的话 | `S.cfg.extra.secrets` / `secretPin` |

样式单独放在 `assets/css/12-only.css`，与 `07-us.css` 同一套纸的语汇。

## 双主题与混排桌面（v16）

- 美化页顶部可整组切换 **雾灰玻璃**（暗壁纸 + 玻璃拟态）/ **奶油浅粉**（柔白纸张）两套主题，存 `S.cfg.ui.theme`，预设壁纸随之联动。
- 主屏为 4 列流式混排：全宽横条（明信片）→ 两枚图标贴竖卡（拍立得）→ 其余图标 → 音乐横卡 + 日历/小对话/纪念日 → 等级/书架/日记/时钟小卡；拖过顺序存 `S.cfg.flow`（`flowVer=3`）。
- 组件样式集中在 `assets/css/13-refine.css`，含主题变量、组件字号层级、空状态与点击反馈。
