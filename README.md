# 里屋

屋子不大，够两个人住。

现在是一间 3D 的屋子。手指拖着转视角，双指或滚轮缩放，点屋里任何一件东西，就开那一间。

| 点哪里 | 开什么 |
| --- | --- |
| 左墙那扇开着缝的门 | 门厅 |
| 右墙的窗 | 这些天 |
| 桌上摊开的本子 | 日记 |
| 墙上的三个相框 | 相册 |
| 靠右墙的书架 | 记忆 |
| 桌上那台收音机 | 说话 |

底部那排文字是备用的：3D 没加载出来（网慢、设备不支持 WebGL）也能点着用。

## 文件

| 文件 | 管什么 |
| --- | --- |
| `index.html` | 骨架。canvas、抬头、面板、接线弹层 |
| `assets/style.css` | 面板和按钮的样式。颜色在顶上 `:root` |
| `assets/panel.js` | 六间房的内容、聊天、接线。跟 3D 无关 |
| `assets/room3d.js` | 屋子本身：几何、材质、灯光、相机、点击。颜色在顶上 `COLORS` |
| `data.js` | 内容：时间轴、日记、相册清单、记忆 |
| `proxy.py` | 可选。本机中转，绕开浏览器跨域 |

3D 的 three.js 从 CDN 拿（unpkg → jsdelivr → esm.sh 依次试），没放进仓库，因为 1.2MB。第一次打开要等几秒。

## 想改的时候

- **换墙色 / 换木色**：`assets/room3d.js` 顶上的 `COLORS`
- **换面板颜色**：`assets/style.css` 顶上的 `:root`
- **换个位置摆家具**：`room3d.js` 里每件东西的 `position.set(x, y, z)`
- **换墙上那句话**：`data.js` 里的 `hero`（3D 里也贴了一份，在 `room3d.js` 搜 `heroSprite`）
- **加减日子/照片/记忆**：只改 `data.js`

## 接线（让「说话」真的能说）

点收音机 → 「接线的地方」，填接口地址、Key、模型，先点「试一下」。

报跨域（Failed to fetch / CORS）就是浏览器不让网页直连接口，跑一下本机中转：

```
python3 proxy.py
```

地址改成 `http://127.0.0.1:8790/v1`，再试。
