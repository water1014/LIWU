# 里屋

屋子不大，够两个人住。

## 屋里有什么

一屏一间，左右滑。

1. 门厅
2. 这些天
3. 日记
4. 相册
5. 记忆
6. 说话

## 怎么往里添东西

除了点着能写的（日记、说话），别的东西都写在 `data.js` 里，改完推上来就生效，不用动 `index.html`。

- **起算日**：不用改文件，在「这些天」那页点一下日期就能填。
- **时间轴**：`data.js` 里的 `timeline`，一行一件事。
- **日记**：`data.js` 里的 `diary`，格式 `{ date, title, body }`。
- **相册**：图放进 `images/` 文件夹，然后在 `data.js` 的 `album` 里加一行 `{ src: 'images/xxx.jpg', date: '2026-11-22', caption: '' }`。
- **记忆**：`data.js` 里的 `memory`，一句一件。

## 一点说明

日记和说话里自己敲的字存在浏览器里，换手机、清缓存就没了。想让它们留下来，就得挪进 `data.js`。
