# 里屋 · LIWU

一间只属于两个人的私人 AI 伴侣空间。当前版本采用原生 HTML、CSS 与 JavaScript，手机优先，无需前端构建步骤。

## 当前页面

- **聊天**：多会话、会话搜索、流式回复、停止生成、思考内容折叠、复制/重新发送/重新生成/删除消息。
- **日记**：浏览预置日记，在本机新增和删除日记。
- **相册**：读取 `data.js` 中的照片清单，点击照片可放大查看。
- **记忆**：展示 `data.js` 中的关系记忆。
- **设置**：OpenAI-compatible 接口配置、系统提示词、温度、上下文条数、流式开关、昼夜主题、起算日、完整数据导入导出。

## 文件

| 文件 | 用途 |
| --- | --- |
| `index.html` | 页面结构与入口 |
| `assets/app.js` | 会话、聊天、日记、相册、记忆、设置与导入导出逻辑 |
| `assets/style.css` | 主题、布局、移动端交互样式 |
| `data.js` | 初始关系记忆、日记、相册和起算日 |
| `proxy.py` | 可选的本机 API 中转 |

旧的桌面/场景实验文件仍留在仓库中作为历史素材，但当前入口不加载它们；LIWU 当前界面是 2D 手机端应用，不使用 3D/WebGL。

## 本地数据

以下现有键名保持不变，升级界面不会清理或重命名它们：

- `liwu.v3`：会话和消息
- `liwu.cfg3`：接口与模型配置（包含 API Key）
- `liwu.diary`：本机新增的日记
- `liwu.since`：起算日

设置中的「导出全部」会导出会话、配置、起算日和本机日记。导出文件包含 API Key，请妥善保管。

## 连接模型

在侧栏打开「设置」，填写兼容接口地址、API Key 和模型名称，再点击「试一下」。接口地址通常填写到 `/v1`，应用会自动补上 `/chat/completions`。

如果浏览器跨域限制导致 `Failed to fetch`，可在自己的设备上运行本机中转：

```bash
python3 proxy.py
```

然后将接口地址填写为 `http://127.0.0.1:8790/v1`。

## 设计原则

- 手机优先，适配安全区、软键盘和独立滚动。
- 黑白为主，蓝灰作为克制的辅助色。
- 保留展开式侧栏，不使用底部导航栏。
- 聊天、日记、相册、记忆、设置各自独立。
- 不删除已有功能，不更改现有本地存储键名。
