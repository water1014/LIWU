# LIWU · 小手机

一台只存在于浏览器里的手机。桌面、聊天、世界书、记忆、表情、日记都在一个静态站点里，数据只写进本机 IndexedDB，不发往任何服务器。

> 这是**多文件工程**版本：源码按层拆开，浏览器直接加载，不再依赖打包。想发给别人一个文件时再用 `build.py` 压成单 HTML。

---

## 怎么跑

**方式一：本地起一个静态服务（推荐）**

```bash
cd liwu
python3 -m http.server 8000
# 打开 http://localhost:8000
```

只有 http/https 下才能注册 Service Worker、装成 PWA、离线打开。

**方式二：直接双击 `index.html`**

也能完整运行（脚本是普通 `<script>`，不是 ES Module），但装不了 PWA，`file://` 下部分浏览器的 IndexedDB 行为不一致。

**方式三：打包成单个 HTML 分享**

```bash
python3 build.py     # 产物：dist/liwu.standalone.html
```

## 这一版补了什么

| 模块 | 说明 |
| --- | --- |
| **多文件工程** | 样式与脚本各自成文件，浏览器原生加载；保留可选打包 |
| **PWA** | `manifest` + Service Worker，可添加到主屏、断网打开 |
| **表情库** | 上传图片、命名、改名、删除可撤销；名字进提示词名单，AI 输出 `[表情:名字]` 渲染成图片气泡 |
| **接口对接层** | 地址自动补 `/v1` 或 `/v1beta`，两种候选各试一次；401/403/404/429/超时/非 JSON 都翻译成人话 |
| **世界书范围** | 全局书对所有角色生效，手动绑定的书只对指定角色生效 |
| **果冻反馈** | 按下 0.08s 快速压缩，松开 0.6s 过冲回弹；只碰 `transform`，不与配色打架 |
| **轻提示可撤销** | 删除表情等操作给出撤销入口，提示条带操作按钮 |
| **我们** | 在一起的天数、今天的提醒、胶囊 / 词云 / 月度 / 小房间的入口 |
| **小房间** | 待办、便签、心愿、打卡四个页签，共用一个入口 |
| **时间胶囊** | 写一封信封起来，到期前打不开；拆开是一张纸 |
| **词云** | 本机分词 + 词表匹配，取高频实词，按频次分档排版 |
| **月度回顾** | 六项数据、每日柱状图，和一封按真实数字写成的信 |
| **额度** | 请求次数、输入 / 输出 token、失败数、七天柱状图 |

原有功能都在：桌面纵向滚动、组件增删与拖动换序、聊天多账号、思考折叠、旁白、长按编辑/删除/重回、气泡与聊天室 CSS、世界书条目（前/中/后 × 始终/关键词/概率）、三级记忆与自动总结、档案、商店、通知、美化、API 三协议、提示词分块开关、数据管理、音乐、书架、纪念日与日记。

「我们」这一组全部离线计算：词云从 IndexedDB 里的消息切词，月度回顾读的是每日消息计数，额度读的是接口返回的 `usage`（没有就按字数估）。

## 数据

- 全部写在浏览器 IndexedDB 的 `LIWU_DB` 里：账号、角色、会话、消息、世界书、记忆、设置、图片文件。
- 图片存 Blob，运行时生成临时 URL 并缓存；刷新后重新生成，不会裂图。
- 表情上传只压超过 300 KB 的图，透明底不会被转黑。
- 「设置 → 数据」可以按表查看占用、单独清空或全部清空。

## 已知取舍

1. 没有真实音频文件，音乐页只是界面里的播放状态。
2. 未配置接口时走本地模拟回复，语气是规则拼的，不是模型。
3. 消息列表按 40 条一屏渐进加载，没有做虚拟滚动；几千条以上会变慢。
4. 桌面组件按纵向流式排列，拖动可改顺序；不做像素级自由定位。
5. 提示词里的世界书与记忆是拼接式注入，不做向量检索。
6. 浏览器直连接口要求对方允许 CORS；不支持的线路需要自建代理。
7. 词云用的是内置常用词表 + 正向最大匹配，不是真分词：生僻词、人名会漏，宁缺勿滥。
8. 额度只统计调用次数与 token，不显示余额——不同中转站计价方式不一样。

## 部署

仓库根目录就是站点根目录，推上去后在 Pages 里选 `main` 分支即可。`.nojekyll` 必须保留，否则 Jekyll 会解析页面里的模板语法。

## 主屏结构（v6）

主屏不再是左右翻页，改成一条纵向滚动的流：

1. **时钟**：滚动时自动收起，把空间让给内容。
2. **全部应用**：12 个应用（聊天 / 我们 / 世界书 / 记忆 / 档案 / 音乐 / 书架 / 时光 / 商店 / 通知 / 美化 / 设置）一次性铺开，新装的应用不会再「藏起来」。
3. **今天**：9 个组件（明信片 / 拍立得 / 小对话 / 音乐 / 纪念日 / 熟悉度 / 日历 / 在读 / 日记）按两列排，全宽卡独占一行，高度由内容决定，不再被格行压扁。

长按任意卡片进入编辑：右上角 × 删除，拖动换序，右上角「恢复默认」回到初始排布。
