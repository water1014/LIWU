# 里屋

进屋是一间 3D 的屋子，聊天藏在屋里的东西后面。

## 怎么进哪间

| 点哪里 | 开什么 |
| --- | --- |
| 左墙那扇门 / 桌上收音机 | 说话（聊天） |
| 桌上摊开的本子 | 日记 |
| 墙上三个相框 | 相册 |
| 右边书架 | 记忆 |
| 台灯 | 设置 |

拖着转视角，双指缩放。底部那排字是退路：3D 没加载出来、网慢、手机不支持 WebGL，点那排一样能用。

回去的路径：聊天页左上角 `≡` → 左下角 **回屋子**。

## 先接线

门 → 合上后点 `≡` → **设置**，或者直接点屋里的台灯。三道菜：

1. 接口地址（`https://api.deepseek.com/v1` 这种，填到 `/v1`）
2. Key
3. 模型

上面三个胶囊能一键填前两个。点 **试一下**，看到“通了”再点 **存好**。

报 `Failed to fetch` 就是跨域，在手机 Ubuntu 里跑：

```
python3 proxy.py
```

地址改成 `http://127.0.0.1:8790/v1`。

## 文件

| 文件 | 管什么 |
| --- | --- |
| `index.html` | 骨架。3D 画布、聊天层、抽屉、全屏页 |
| `assets/home3d.js` | 屋子本身：几何、材质、灯光、相机、点击。颜色在 `COLORS` |
| `assets/app.js` | 聊天那块：会话、流式、设置、导入导出 |
| `assets/style.css` | 聊天和面板的样式，两套主题 |
| `data.js` | 内容：时间轴、日记、相册清单、记忆 |
| `proxy.py` | 可选。本机中转 |

想改屋子就改 `home3d.js`，想改聊天就改 `app.js`，两边不牵着。

## 能干什么

- **多个会话**：抽屉里能搜、能改名、能删
- **流式吐字**，能按停
- **思考链**折在“它想了一下”里
- **单条操作**：复制、重发、重新生成、删掉
- **设置**：系统提示词、温度、上下文条数、流式开关、夜间、起算日
- **导出 / 导入**（一份 JSON）
- 日记 / 相册 / 记忆

## 还没有的

工具调用、插件、看图、语音、记忆检索（记忆只是一页清单，不参与上下文）、对话写回仓库、图上传来。

## 数据在哪

全部在 localStorage：`liwu.v3`（会话）、`liwu.cfg3`（配置，含 Key）、`liwu.diary`、`liwu.since`。换手机或清缓存就没了，想搬走用“导出全部”。

## 为什么 three 不放仓库

1.2MB。从 unpkg 拿，拿不到就试 jsdelivr、esm.sh。第一次打开要等几秒，之后就缓存了。
