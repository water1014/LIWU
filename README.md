# 里屋

打开是一张摊开的桌子（three 场景）：一本杂志、压在杂志下的旧纸、一张拍立得、一张便签、一台唱片机、一张工牌。

## 桌上什么开什么

| 桌上 | 开什么 |
| --- | --- |
| 杂志（封面大图） | 相册 |
| 杂志下露出边的那张纸 | 记忆 |
| 拍立得 | 相册 |
| 黄色便签 | 日记 |
| 黑胶唱片机 | 说话 |
| 白色工牌 | 设置 |

**拖**：按住任何一件东西拖，它会离开桌面跟着手走；松手落回去，位置存在本机。
**点**：按下去不到 7 像素就松手，是点开那一间。
**复位**：双击抬头中间的时间，全部弹回原位。

底部那排字是退路，任何东西点不到都能从那进。

## 那本杂志

版式和字都是现画的（canvas 纹理），内容从 `data.js` 读：

- 刊名「里屋」，下面一行英文，右上角 `VOL. 01 / 2026·11`
- 中间封面大图 = `album` 里的第一张图
- 封面语 = `hero`
- 本期要目 = `memory` 前三条标题
- 页脚 = `weather` 和起算日算出来的第几天

换主题时纸和字一起变暗。

## 先接线

工牌 → 填地址 / Key / 模型 → 试一下 → 存好。

报 `Failed to fetch` 就是跨域，在手机 Ubuntu 里跑：

```
python3 proxy.py
```

地址改成 `http://127.0.0.1:8790/v1`。

## 文件

| 文件 | 管什么 |
| --- | --- |
| `index.html` | 骨架：画布、抬头、聊天层、抽屉、全屏页 |
| `assets/desk3d.js` | 桌子与桌上所有东西：几何、画布纹理、灯光、相机、拖拽 |
| `assets/desk.css` | 叠在上面的抬头、提示、底部 |
| `assets/app.js` | 聊天：会话、流式、设置、导入导出 |
| `assets/style.css` | 聊天和面板的样式 |
| `data.js` | 内容：封面语、天气、备忘、日记、相册清单、记忆 |
| `proxy.py` | 可选中转 |

## 放照片

图丢进 `images/`，在 `data.js` 的 `album` 里加一行：

```
{ src: 'images/xxx.jpg', date: '2026-11-22', caption: '一句说明' }
```

第一张上杂志封面，第二张上拍立得。
