# 里屋

打开是一张摊开的桌子：早报、拍立得、便签、唱片机、工牌。点东西就进去。

## 桌上什么开什么

| 桌上 | 开什么 |
| --- | --- |
| 早报左欄「备忘」 | 记忆 |
| 早报右欄大图 | 相册 |
| 拍立得 | 相册 |
| 黄色便签 | 日记 |
| 黑胶唱片机 | 说话（聊天） |
| 白色工牌 | 设置 |

抬头：左边 `≡` 开会话列表，中间时间日期，右边「预览：白天」点一下切夜晚。
手在屏幕上动一动，桌子会微微歪（视差）。
底部那排字是退路，任何东西点不到都能从那进。

回到桌子：聊天页 `≡` → 左下角 **回桌子**。

## 先接线

工牌 → 填地址 / Key / 模型 → 试一下 → 存好。

报 `Failed to fetch` 就是跨域，在手机 Ubuntu 里跑：

```
python3 proxy.py
```

地址改成 `http://127.0.0.1:8790/v1`。

## 文件

| 文件 | 管什么 |
| --- | --- |
| `index.html` | 骨架：桌面、聊天层、抽屉、全屏页 |
| `assets/desk.css` | 桌子：报纸 / 拍立得 / 便签 / 唱片 / 工牌 / 夜间 |
| `assets/desk.js` | 桌子上的交互：时间、天数、备忘、图、视差、主题 |
| `assets/app.js` | 聊天：会话、流式、设置、导入导出 |
| `assets/style.css` | 聊天和面板的样式 |
| `data.js` | 内容：天气、备忘、日记、相册清单、记忆 |
| `proxy.py` | 可选中转 |

想改桌子就改 `desk.css`；想改报上的字、温度、备忘就改 `data.js`；想改聊天改 `app.js`。三块不牽着。

## 放照片

图丢进 `images/`，然后在 `data.js` 的 `album` 里加一行：

```
{ src: 'images/xxx.jpg', date: '2026-11-22', caption: '一句说明' }
```

第一张上早报，第二张上拍立得。
